# anndata.claude

`anndata.claude` is an R port of Python
[anndata](https://anndata.readthedocs.io) for annotated data matrices.

Its first priority is full compatibility with the anndata on-disk
formats. An object read from an h5ad file or zarr store is equal
whichever language wrote it, and files written by R are structurally
equivalent to files written by Python. The in-memory `AnnData` object
supports that goal and aims for feature parity with Python.

The package was written by Claude (Anthropic’s AI models) in an
autonomous development loop, supervised by a human maintainer (see
[Development](#development)).

## Relationship to Python anndata

Python anndata release 0.13.4 is the only reference for behaviour. This
package matches its observable behaviour (values, errors, warnings and
files written) but is idiomatic R rather than a line-by-line
translation. Indexing is 1-based with negative exclusion, and `AnnData`
objects have reference semantics (R6) like their Python counterparts.

Every known difference is listed with its reason in
[`vignette("deviations")`](https://lazappi.github.io/R-anndata-claude/articles/deviations.md).

## Features

- The `AnnData` object with `X`, `obs`, `var`, `obsm`, `varm`, `obsp`,
  `varp`, `layers`, `uns` and `raw`, with `obs` and `var` as
  [`S4Vectors::DataFrame`](https://rdrr.io/pkg/S4Vectors/man/DataFrame-class.html)s
- Views with copy-on-write when subsetting
- [`read_h5ad()`](https://lazappi.github.io/R-anndata-claude/reference/h5ad.md)
  and
  [`write_h5ad()`](https://lazappi.github.io/R-anndata-claude/reference/h5ad.md)
  for every current anndata encoding except awkward arrays, with
  compression
- [`read_zarr()`](https://lazappi.github.io/R-anndata-claude/reference/zarr.md)
  for zarr v2 and v3 and
  [`write_zarr()`](https://lazappi.github.io/R-anndata-claude/reference/zarr.md)
  for zarr v3 (including sharding)
- Backed mode for h5ad (`read_h5ad(backed = "r")`) and
  [`sparse_dataset()`](https://lazappi.github.io/R-anndata-claude/reference/sparse_dataset.md)
- Lazy reading with `DelayedArray`
  ([`read_lazy()`](https://lazappi.github.io/R-anndata-claude/reference/read_lazy.md)
  and
  [`read_elem_lazy()`](https://lazappi.github.io/R-anndata-claude/reference/read_elem_lazy.md))
- [`concat()`](https://lazappi.github.io/R-anndata-claude/reference/concat.md)
  with Python’s join, merge and label options
- Files from older anndata releases (0.6 onwards)
- [`read_csv()`](https://lazappi.github.io/R-anndata-claude/reference/read_text.md),
  [`read_text()`](https://lazappi.github.io/R-anndata-claude/reference/read_text.md),
  [`read_mtx()`](https://lazappi.github.io/R-anndata-claude/reference/read_mtx.md),
  [`read_umi_tools()`](https://lazappi.github.io/R-anndata-claude/reference/read_umi_tools.md),
  [`read_hdf()`](https://lazappi.github.io/R-anndata-claude/reference/read_hdf.md),
  [`read_excel()`](https://lazappi.github.io/R-anndata-claude/reference/read_excel.md)
  and
  [`write_csvs()`](https://lazappi.github.io/R-anndata-claude/reference/write_csvs.md)
- Python’s settings
  ([`anndata_settings()`](https://lazappi.github.io/R-anndata-claude/reference/anndata_settings.md))
  and its warnings and errors as classed R conditions

Not supported: loom (deprecated in Python), writing zarr v2, zip stores
and the experimental Python features (`AnnCollection`, `concat_on_disk`,
awkward arrays). Reading is slower than Python on large files. See the
known limitations in `NEWS.md` for details.

## Installation

Install the development version from GitHub with
[pak](https://pak.r-lib.org), which also installs the Bioconductor
dependencies and the development version of
[Rarr](https://github.com/Huber-group-EMBL/Rarr):

``` r

# install.packages("pak")
pak::pak("lazappi/R-anndata-claude")
```

The package has compiled code that links to the HDF5 library from
Rhdf5lib. On macOS that library needs OpenSSL, which can be installed
with
`source("https://mac.R-project.org/bin/install.R"); install.libs("openssl")`
(run as an administrator) or Homebrew.

## Usage

``` r

library(anndata.claude)

X <- matrix(as.numeric(1:12), nrow = 3)
obs <- data.frame(cell_type = c("T", "B", "T"), row.names = paste0("cell", 1:3))
var <- data.frame(row.names = paste0("gene", 1:4))
adata <- AnnData(X, obs = obs, var = var)
adata$layers[["counts"]] <- X * 2

path <- tempfile(fileext = ".h5ad")
write_h5ad(adata, path)
read_h5ad(path)
```

Start with
[`vignette("anndata-claude")`](https://lazappi.github.io/R-anndata-claude/articles/anndata-claude.md),
or browse the documentation at
<https://lazappi.github.io/R-anndata-claude/>.

## Directory structure

### The package

| Path | Contents |
|----|----|
| `R/` | Package code, grouped by file prefix (`anndata*`, `io-*`, `backed*`, `lazy-*`, `concat*` and so on) |
| `src/` | A small C helper for HDF5 compound types, linked to Rhdf5lib (ADR 0008) |
| `man/` | Help pages generated by roxygen2 |
| `vignettes/` | The getting started guide and the list of deviations from Python |
| `tests/testthat/` | testthat tests and their helpers |
| `tests/testthat/fixtures/` | Files written by Python anndata and JSON tables of Python’s expected behaviour |
| `tests/python/` | The uv project pinning Python anndata 0.13.4, with scripts that generate fixtures and compare files |
| `DESCRIPTION`, `NAMESPACE`, `NEWS.md`, `LICENSE` | Standard package files |
| `_pkgdown.yml` | pkgdown site configuration (built into the git-ignored `pkgdown-site/`) |
| `.github/workflows/` | GitHub Actions for `R CMD check`, lint, coverage and the pkgdown site |
| `air.toml`, `.lintr` | Formatter and linter settings |

## Development

Development runs as a “Ralph loop”: `scripts/ralph.sh` starts a fresh
Claude Code run for each ticket in `fix_plan.md`, which works
test-first, checks its result against Python and commits. The human
maintainer writes the specs with Claude, approves tickets and decides
releases.

The full check, which must pass before every commit, is:

``` sh
scripts/check.sh --package  # format, lint, document and R CMD check without tests
scripts/check.sh --tests    # every test
```

Tests that compare with Python need [uv](https://docs.astral.sh/uv/),
and are skipped without it or when `ANNDATA_SKIP_PYTHON` is set.
