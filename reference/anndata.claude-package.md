# anndata.claude: Annotated Data Matrices and Their On-Disk Formats

An R port of Python 'anndata' (reference release 0.13.4) for annotated
data matrices. The first priority is compatibility with the anndata
on-disk formats, so that objects read from a file are equal whichever
language wrote it.
